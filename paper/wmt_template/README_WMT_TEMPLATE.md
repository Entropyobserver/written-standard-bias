This folder contains a WMT-oriented copy of the paper using the official
*ACL LaTeX style files.

Source:
- WMT 2025 submission instructions state that papers should follow EMNLP
  formatting guidelines.
- The official *ACL formatting guidelines point authors to the
  `acl-org/acl-style-files` repository.

Main files:
- `wmt.tex`: WMT/ACL-style paper source copied from the current EAMT version.
- `wmt.bib`: bibliography copied from the current EAMT version.
- `acl.sty`, `acl_natbib.bst`: official ACL style files.
- `acl_latex_template.tex`: original downloaded ACL example template.

The current `wmt.tex` uses `\usepackage[review]{acl}` for anonymous review
format. Change `review` to `final` only for camera-ready formatting.
